# 🌍 МикронацииВики

Свободная энциклопедия микронаций.

## Как добавить/изменить статью?

1. **Сделайте fork** репозитория
2. **Отредактируйте** файл в папке `/pages/`
3. **Создайте Pull Request** с вашими изменениями
4. **Дождитесь** проверки и публикации

## Структура
- `/pages/` — все статьи о микронациях
- `/css/` — стили сайта
- `/js/` — скрипты

## Правила
- Статьи должны быть нейтральными
- Только факты, без вымысла
- Указывайте источники
